# Facial & Emotion Detection (YOLOv8)

A demo that detects faces and classifies the emotion (Anger, Contempt, Disgust,
Fear, Happy, Neutral, Sad, Surprise) on images using two trained YOLOv8 models.

Upload a photo or use the webcam.
